# Abu Gplan AI Copilot

A full-stack AI copilot starter built with React/Vite and Node/Express. The supplied Abu Gplan logo is included in `client/public/logo.png`.

## Features
- Professional responsive AI chat interface
- Abu Gplan branding/logo
- New conversations and conversation history
- Delete conversations
- Backend API
- OpenAI-compatible AI provider adapter
- Health check endpoint
- Mobile-friendly layout

## Setup
1. Install Node.js 18+.
2. Run `npm run install-all`.
3. Copy `server/.env.example` to `server/.env`.
4. Add your AI provider URL, API key and model.
5. Run `npm run dev`.
6. Open the Vite frontend URL shown in the terminal.

The phrase "solve any problem" means the app is designed as a general-purpose copilot; actual capabilities depend on the AI model/provider connected to the backend.
